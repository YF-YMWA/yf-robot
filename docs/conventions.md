# 开发约定

用户定下的规矩，写在这里免得忘。

---

## 1. 每项功能都必须有面板入口

**规矩**：新做一个功能，不能只有接口或只靠手敲命令 —— 必须在控制台里有对应的界面。

对照清单（加功能时逐条过）：

- [ ] 有开关或表单（能改、能存）
- [ ] 有列表或状态显示（能看见当前是什么样）
- [ ] 有删除/撤销入口（能反悔）
- [ ] 打开页面时自动加载数据（不用手动点刷新）
- [ ] 校验失败时给一句人话（不是 `undefined` 或英文报错）

**为什么**：这套东西是给人双击就用的，不是给开发者敲 curl 的。
「有接口没界面」等于没有这个功能。

**已有功能的检查结果**：

| 功能 | 面板入口 |
| --- | --- |
| 对话模型 / 看图 / 画图 / 语音 / 搜索 | ✅ 模型与功能页 |
| 工具权限档位 | ✅ 模型与功能页下拉 |
| 审批（微信里问） | ✅ 走对话，无需页面 |
| 记忆（含备份/恢复） | ✅ 记忆页 + 两个 bat |
| 素材库 / 她画的图 | ✅ 素材页 |
| 主动搭话 / 主动画图 | ✅ 主动功能页 |
| **定时任务** | ✅ 主动功能页新增卡片 |
| 联网学习 / 插件 / 逻辑库 | ✅ 各自页面 |
| 后台作业 | ⚠️ 无页面（只影响内部调度，先不加） |

---

## 2. 改完必须自己跑一遍

- `runtime\node.exe tools\run-tests.mjs`（全量单测）
- `runtime\node.exe tools\check-all.mjs`（运行时自检）
- `runtime\node.exe tools\check-console-js.mjs` / `check-console-fns.mjs` / `check-console-pages.mjs`（面板三项）

**不能只跑单元测试**：面板是纯前端，单元测试覆盖不到。
面板改动至少要过上面三个检查，能打开页面自己点一遍更好。

---

## 3. 新增配置项要过四关

漏一处的后果都是**静默失效**——面板保存后不变，日志也不报错。

| 关卡 | 位置 | 漏了会怎样 |
|---|---|---|
| ① 声明 | `core/config-schema.mjs` 的 `SECTION_SCHEMA` | `applyPatch` 直接丢弃，改配置毫无反应 |
| ② 默认值 | `core/config.mjs` | 新装用户拿到 undefined，行为不确定 |
| ③ 读接口 | `#publicConfig`（手写段落时要补） | 面板显示默认值，用户以为没保存 |
| ④ 保存分支 | `#saveConfig`（手写段落时要补） | 保存被丢弃 |

真实事故（两次）：`tools.approval` 没进 schema；`wechat.voiceMode` 读接口漏返回 —— 都是「保存后不变」。

**现在 ③ 已经自动兜底**：`#publicConfig` 用 schema 当基准补齐缺失字段
（密钥类不补），所以新字段只要 ① ② 做了，读接口自动就有。

自检：`runtime
ode.exe toolscheck-config-coverage.mjs`
（服务在跑时会实时比对，报出读接口漏了哪些字段）。

## 4. 面板控件必须「能存能读」

可保存的控件（`sw*` 开关 / `sel*` 下拉）要同时有：

1. **保存**：onchange 里调接口写配置
2. **回填**：加载配置时把值写回控件

漏回填的表现是「**保存成功，刷新后变回默认值**」——用户以为没存上，其实是界面没读。

自检：`runtime
ode.exe toolscheck-console-fill.mjs`
（扫页面里所有 sw*/sel* 控件，检查有没有对应回填代码）

真实事故：`selVoiceMode`、`swAutoClean` 都漏过回填。

## 5. 面板函数名不许重复

同名函数会互相覆盖，症状是**「某个页面突然没了」**。

真实事故：新增「各卡数据」页时写了 `loadCards()`，和原版角色卡列表的
`loadCards()` 重名 —— 后者被覆盖，用户打开「身份 → 角色卡」看不到卡。

自检：`runtime
ode.exe toolscheck-console-dup.mjs`

## 6. 出错要能查

- 新功能的关键失败点必须有日志，日志要能指出「哪个功能、什么原因」
- 不要写「失败」两个字就完事（参照 `docs/BUGS.md` 里「无返回」那一条的教训）

---

## 4. 框架与适配器保持分离

- 主仓（`YF-Robot`）**不出现**任何微信/平台自动化代码
- 需要平台能力时，走 `adapters/<名字>/` 或独立仓库
- 提 PR / 提交前自查一遍：主仓里有没有 Windows 窗口、剪贴板、UIA 相关代码
