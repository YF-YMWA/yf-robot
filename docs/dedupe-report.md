# 功能查重报告

时间：2026-10-28
范围：`core/` 全部模块 + 控制台全部页面

---

## 一、代码层

### 已合并

| 项 | 原来 | 现在 | 影响 |
|---|---|---|---|
| **HTML 转文本** | 3 份：`kb.mjs`（简单）、`learning.mjs`（最细）、`safe-fetch.mjs`（简单） | 1 份：`core/html-text.mjs` | 同一段 HTML 出来文本一致 |
| **网页抓取** | 4 套：`learning`、`logic-learn`、`rss`、`media` 各写各的 | 统一 `core/safe-fetch.mjs` | 补上 3 处 SSRF 漏洞 |

合并时保留的是 `learning.mjs` 那份 —— 它会丢掉 script/style/nav/header/footer，
先解实体再剥标签（防双层转义），比另外两份细致。

### 发现的安全问题（已修）

| 模块 | 原来的问题 | 后果 |
|---|---|---|
| `learning.mjs` | 只检查协议就 `fetch(url, {redirect:'follow'})` | 能抓 `127.0.0.1:8899/api/admin/config`（读到配置）、`169.254.169.254`（云元数据） |
| `rss.mjs` | 同上 | 同上 |
| `media.mjs` | 直接 `fetch(url)`，无任何校验 | 恶意适配器可让核心读内网 |

三处都改成走 `safe-fetch`：只允许公网 http/https，
拒绝 file 协议 / 内网段 / 云元数据 / 非常规端口 / 超大响应，跳转逐跳校验。

### 看起来重复、实际不该合并的

| 项 | 为什么留着 |
|---|---|
| `learning.mjs` vs `logic-learn.mjs` | 都是「抓→提炼→入库」，但提炼目标不同（词 vs 规则）、提示词不同、入库目标不同。共用的是抓取和过滤，已经共用 |
| `auto-learn.mjs` vs `learning.mjs` | 前者只决定**什么时候**学（节流），后者负责**怎么**学。职责清晰，合并会糊 |
| `memory.mjs` vs `digest.mjs` | 一个是逐条事实记忆，一个是滚动摘要。用途不同 |
| `words.mjs` 与 `context.mjs` | 前者产文本，后者管预算和顺序。已经通过 `styleText` 对接 |

## 二、控制台

### 已合并：15 页 → 11 页

| 新入口 | 包含 | 合并理由 |
|---|---|---|
| **资料** | 知识库 / 逻辑库 / 词库 | 三者都是「塞进提示词的内容」，只是类型不同 |
| **身份** | 角色卡 / 主人设置 | 都在定义「她是谁、你是谁」 |
| **运行** | 接入状态 / 日志 | 都是看服务活得好不好的 |

实现方式：侧栏只留一个入口，页面顶部出现标签栏，组内切换。
支持 `#kb` 这种地址直接定位到具体标签。

### 没合并的

| 页面 | 理由 |
|---|---|
| 总览 / 对话调试 / 模型与功能 | 各自独立，没什么共性 |
| 记忆 | 和「资料」不同：记忆是聊出来的，资料是你喂的 |
| 主动功能 / 素材库 / 联网学习 / 插件 | 功能明确、互不重叠 |

## 三、还有两处「像重复但不算」的地方

**① `learning.mjs` 里有两个抓取函数**：`fetchSiteText` 和 `fetchSiteImages`。

看着像重复，实际一个抓正文、一个抠图，提取逻辑不同。
共用的是 `safeFetchText` 和 `extractImageUrls`，已经共用。

**② 控制台「联网学习」页有 9 张卡片**，是全站最挤的一页。

潜在合并方向：

```
学习网络用语 + 对话时自动学习   → 「自动学习」
下载图片素材 + 定向网页抓图     → 「图片采集」
RSS 订阅学习 + 每日热点摘要     → 「订阅」
```

**没动**，因为它们是不同功能的开关，合起来反而要跳两层才能找到某个开关。
如果你觉得太挤，可以按上面这三分法重排。

## 四、怎么复现这份审计

```bash
# 代码层：找出多份同名实现
grep -rn "function htmlToText\|function htmlToPlainText" core/

# 抓取入口：哪些模块在抓外部 URL
grep -rln "await fetch(\|safeFetchText" core/

# 控制台：页面与卡片
node -e "…"   # 见 tools/ 目录下的临时脚本

# 页面可达性（每个页面都有入口、没有孤儿页）
node tools/check-console-pages.mjs
```
