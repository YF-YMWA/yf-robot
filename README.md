# YF-Robot

一个能陪聊、能干活、能进微信的人设化 AI 助手。

Node.js + Python，Windows 桌面双击即用。支持自定义角色卡、长期记忆、联网搜索、看图、画图、语音转写，以及通过 [DeepSeek Harness](https://github.com/deepseek-ai) 反向调用 agent 干活。

> **免责声明**：微信自动化违反《微信个人账号使用规范》，有被封号的风险。本项目仅用于个人学习研究，请自行承担后果。详见 [合规说明](#合规说明)。

## 快速开始

### 方式一：下载发行包（推荐给不写代码的人）

到 [Releases](../../releases) 下载最新 `YF-Robot-vX.zip`，解压到**纯英文路径**（例如 `D:\YF-Robot`），双击 `YF-Robot.bat`。

包内自带 Node 和 Python 运行时，**不需要另外安装**。

> 不要解压到桌面或「文档」——Windows 的「受控文件夹访问」可能拦住写配置。

### 方式二：从源码运行

```bash
git clone https://github.com/YF-YMWA/yf-robot.git
cd yf-robot

# 1. 检查 Node 版本（当前没有第三方依赖）
node --version   # >= 18

# 2. 首次配置：复制示例配置，填 Key
cp config.example.json config.json

# 3. 启动
node app.mjs
```

打开 http://127.0.0.1:8899/console ，在「模型与功能」里填 Key。

> 不需要装 Python。核心是纯 Node；
> 接聊天平台要另跑一个适配器（独立项目，自备环境）。

### 需要的 Key

| 用途 | 服务 | 是否必须 |
|---|---|---|
| 对话 | [DeepSeek](https://platform.deepseek.com/) | **必须** |
| 看图 | [智谱 GLM-4V](https://open.bigmodel.cn/) | 可选，有免费额度 |
| 画图 | [智谱 CogView](https://open.bigmodel.cn/) | 可选，有免费版 |
| 联网搜索 | [博查](https://open.bochaai.com/) | 可选 |
| 语音转写 | [阿里云百炼](https://bailian.console.aliyun.com/) | 可选 |

只填对话 Key 就能用，其他功能会自己降级。

## 接聊天平台（适配器）

**这个仓库只包含框架，不含任何平台的登录、协议逆向或自动化代码。**

核心对外只提供一套 HTTP 协议：消息进来、回复出去、图片上传。

```
任何能收发消息的程序  ──HTTP──▶  YF-Robot 核心
（微信 / QQ / Telegram / 自己写的）
```

- 协议：[`docs/adapter-protocol.md`](docs/adapter-protocol.md)
- 骨架：[`examples/adapter-skeleton/`](examples/adapter-skeleton/) —— 跑起来就能看到端到端通了
- 不接任何平台也能用：控制台网页里可以直接聊

> 微信适配器是**另一个项目**，单独发布、单独声明风险。
> 微信自动化违反《微信个人账号使用规范》，有封号风险，与本仓库无关。

## 核心功能

### 功能一览

| 能力 | 关键点 |
|---|---|
| **角色卡** | Character Card V2，控制台新建/编辑，**切换立即生效** |
| **长期记忆** | 会话落盘、事实提取、跨会话隔离、群聊按发言人分开记 |
| **定向白名单** | 只收指定 wxid 发的图；三级主人识别，昵称冒充拿不到任何权限 |
| **群聊策略** | @ 才回 / 叫名字也回 / 接话窗口 / 每小时上限 / 群里指令权限 |
| **看图** | 收到的图（含 GIF、wxgf 容器）自动识别成文字再参与对话 |
| **画图** | 按描述生成图片，可发到微信 |
| **语音** | 微信语音转文字 |
| **联网** | 需要实时信息时搜索；查不到就说查不到，不瞎编 |
| **素材库** | 感知哈希去重、自动情绪标签、按语气挑图、动图保留动画 |
| **词库** | 网络用语 568 条 / 回怼库 206 条 / 缩写 30 条，可持续学习 |
| **后台运行** | 可选「关网页就停服务」，带三道退路 |
| **Key 保护** | 原子写盘、守卫、50 份归档、变更审计 |
| **可插拔接入** | 任何平台写成适配器即可接入，核心不含平台代码 |
| **插件** | `plugins/` 下放目录即可加工具和钩子，不用改核心 |
| **知识库** | 导入文档，聊天时自动检索参考（.txt/.md/.docx/.html） |
| **逻辑库** | 存「遇到情况怎么做」的经验，可手写、可从网页学（默认要审核） |
| **词库** | 网络用语 / 回怼库 / 缩写对照，按语气只注入用得上的那类 |
| **语音合成** | 文字转语音发出去（阿里云百炼，和语音转写共用 Key） |

### 角色卡

标准 [Character Card V2](https://github.com/malfoyslastname/character-card-spec-v2) 格式，放在 `cards/*.json`。

控制台可以新建/编辑/删除，**切换立即生效**（不用重启）：

```json
{
  "spec": "chara_card_v2",
  "spec_version": "2.0",
  "data": {
    "name": "鲸鲸",
    "speaker": "主人",
    "description": "深蓝色长卷发，鲸尾发夹…",
    "personality": "懒、馋、嘴硬心软",
    "system_prompt": "说话简短，偶尔撒娇",
    "first_mes": "主人回来啦"
  }
}
```

### 长期记忆

- **会话落盘**：每轮对话写 `data/sessions/<id>.json`，重启、适配器断线重连都接着聊
- **事实提取**：自动从「我叫X」「我喜欢Y」里抽事实，问句不抽（避免把「我最喜欢的颜色是什么」记成「颜色=什么」）
- **摘要压缩**：历史过长时压成摘要，不丢上下文
- **跨会话**：不同人、不同群各自独立，互不串味
- **群聊按人隔离**：同一群里 A 报过名字，B 问「我叫什么」不会答成 A 的；重名时会说「分不清」

### 定向白名单（收藏范围）

控制台 →「主人设置」→ 图片收藏。

| 设置 | 行为 |
|---|---|
| 留空 | 谁发的图都收（默认） |
| 填了 wxid | **只收这些会话 / 发送者发的图**，别人的图不落盘 |

适合：群里人多只想存自己和朋友的图；不想让陌生人的图堆满素材库。

填的是 `wxid_xxx`，不是昵称——昵称谁都能改。控制台可以从已知联系人里直接选。

### 主人识别（三级）

| 级别 | 判定 | 能用工具 | 能听私事 |
|---|---|---|---|
| 已验证 | wxid 精确匹配 | ✅ | ✅ |
| 仅昵称 | 昵称对上了，wxid 没对上 | ❌ | ❌（会说「光凭昵称我认不了」） |
| 陌生人 | 都不匹配 | ❌ | ❌ |

### 群聊策略

控制台 →「主动功能」→ 群聊策略。

| 设置 | 说明 |
|---|---|
| 只在 @ 时回 | 开：只有 @、叫名字、主人说话才回；关：还会低概率主动插话 |
| 主人总是回 | 主人在群里说话，不 @ 也回 |
| 叫她什么 | 群里叫到这些词就算在叫她 |
| 接话窗口 | 被 @ 之后继续正常聊天的时间（默认 8 分钟） |
| 每小时上限 | 防止刷屏 |
| 群里的主人 | 留空 = 用「主人设置」名单 |

群指令 `/mute` `/unmute` `/reset` `/who`：只有主人或群管理员能用。

### 表情包 / 动图

- 收到图片、表情包自动收藏到素材库，用**感知哈希（dHash）**去重——同一张图被截两次、转两次也不会重复入库
- **动图**：微信 4.x 把 GIF 存在 `wxgf` 容器里（一段 HEVC 视频）。本项目用 ffmpeg 整段转成动画 GIF，所以素材库里能动、发出去也是动图
- **按语气挑图**：每张图有描述和情绪标签，回复后按当前语气挑贴合的，而不是随机甩

### 联网学习

- 自动从搜索 / 定向网站 / RSS 学网络用语，学完直接进词库
- 每日热点摘要：抓订阅源，总结成几条存进共享记忆
- 频率可控：每 N 轮 / 最小间隔 / 每日上限

### 反向调用 DSH

配置里开启后，遇到复杂任务它会调用 [DeepSeek Harness](https://github.com/deepseek-ai) 的 ACP 接口干活，并且**复用 DSH 会话号**——DSH 那边也记得之前聊过什么。

### Key 与崩溃保护

- 写配置前留 `.bak`，另维护 `data/key-archive/`（50 份快照）
- 启动时发现 Key 空了自动从归档补回
- `data/key-audit.log` 记录每次 Key 变化
- 原子写盘（临时文件 + 改名），不会留半个 JSON
- 适配器崩溃由它自己负责重启，核心不做假设

## 开发

```bash
# 单元测试
node --test tests/

# 功能自检（需要服务在跑）
node tools/check-all.mjs

# 控制台 JS 语法检查
node tools/check-console-js.mjs
node tools/check-console-fns.mjs

# 打包发行版
node tools/pack.mjs              # 含运行时，约 250MB
node tools/pack.mjs --no-runtime # 不含运行时，约 3MB
```

### 打包会自动做这些检查

- 敏感信息扫描（Key、wxid、本机路径、第三方 bot token）
- **文件名**扫描（防止 `wxid_xxx_538_h.png` 这类泄露）
- 完整性检查（18 个关键文件缺一不可）
- 隐私目录排除（`data/`、`credentials/`、任何层级的 `data/`）

## 合规说明

**请务必读这一段再决定是否使用。**

1. **本仓库不含任何平台的自动化代码**
   核心只做「收消息 → 生成回复 → 返回」，不登录任何平台、不逆向任何协议、不读任何本地数据库。
   平台接入由独立适配器负责，那些项目的风险由它们自己承担。

2. **不要用于骚扰、营销、刷屏**
   项目里所有「主动搭话」「主动分享」默认关闭，就是为了避免这个。

3. **数据都在你本地**
   会话、图片、语音都存在 `data/`，不上传任何服务器。但 `config.json` 里有 API Key，**别把配置文件发给别人**。

4. **如果你接微信**
   那属于适配器的范畴。微信自动化违反《微信个人账号使用规范》，**有封号风险**。
   本项目不提供、也不推荐任何具体适配器实现。
